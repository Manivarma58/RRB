Exam Instructions & Marking Guidelines

RRB Technician Grade-I (Signal) Computer Based Test (CBT)

1. General Instructions:

  • Each of the 4 mock tests contains exactly 100 Multiple Choice Questions (MCQs).
  • Total duration allowed for each individual mock test is 90 minutes (5400 seconds).
  • The countdown timer in the top header indicates remaining time. When timer reaches 00:00, the test will be submitted automatically.

2. Marking Scheme (Official RRB Rules):

  • +1.0 Mark for every correct answer.
  • -0.33 Mark (1/3rd penalty) for every incorrect answer.
  • 0.0 Mark (No penalty) for questions left unattempted.

3. Question Palette Colors:

  • Green: Question answered and saved.
  • Red: Question visited but not answered.
  • Yellow / Orange: Marked for Review (not answered).
  • Purple with Check: Answered and Marked for Review.
  • Gray: Question not yet visited.

4. Keyboard Shortcuts:

Press 1, 2, 3, 4 (or A, B, C, D) to select options quickly · Alt + N for Save & Next · Alt + P for Previous · Alt + M for Mark for Review.
